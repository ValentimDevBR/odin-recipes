# Odin Recipes

This project is part of The Odin Project's Foundations course. It consists of a basic recipe website built to practice fundamental Web Development skills.

## Skills Demonstrated
By completing this project, I will have demonstrated the ability to:
- Set up a Git repository and manage version control with GitHub.
- Structure web content using semantic HTML5.
- Create and manage multi-page navigation using relative links (`<a>` tags).
- Work with image paths (`<img>` tags) and proper folder organization.
- Write clean and readable HTML code following best practices.
